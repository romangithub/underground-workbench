Why this exists

The solver is already free. What costs time is stitching import, run, plots, and a deliverable report. Workbench targets that glue — not a new numerical engine.

Free stack

mf6 + ModelMuse / FloPy — full power, you assemble the pipeline yourself.

Paid GUIs

Flex, GMS, FEFLOW — mature products, high seat cost and vendor lock.

Workbench

One local UI on native mf6: import site package → verifyable report path.

Default workflow

Same physics as USGS MODFLOW 6. Different packaging of the day-to-day loop.

01
ImportSite package: boundary, wells, observations, surface, optional rivers
02
BuildStructured grid from extents / spacing; layers and top surface
03
RunNative USGS mf6 subprocess — real HDS/CBC, not prebaked heads
04
CalibrateObserved vs computed heads, MAE / improvement, residuals
05
View & reportPlan / Section / 3D + engineering report with provenance

Demo fixtures (client_site_alpha / beta) are synthetic. No personal data and no live client object — see site package audit.
